# Stonewatch — web build

Публічне дзеркало прод-білду гри **Stonewatch: Idle Castle Defense** для GitHub Pages.

Генерується автоматично: `npm run deploy` у сорс-репо
([Stonewatch2D](https://github.com/ValeriiTsarov/Stonewatch2D)) робить прод-білд і дзеркалить
`dist/` сюди. **Руками нічого не редагувати** — наступний деплой перезапише.
